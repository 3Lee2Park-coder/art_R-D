WHY RESTART

방문객 수를 넘어,
무엇이 기억되었는지를.

전시가 끝나면 관람객은 돌아가고, 현장의 기억도 흩어집니다. 어떤 작품이 기록되었는지, 누가 관심을 표현했는지, 어떤 구역에서 반응이 나타났는지 다시 살펴볼 수 있다면 다음 전시를 준비하는 관점도 달라집니다.

01

관람객의 반응을 알기 어렵습니다

입장객 수만으로는 어떤 작품이 관람객의 시선을 끌었는지 확인하기 어렵습니다.

02

관심과 문의가 흩어집니다

작품에 대한 질문과 연락처, 후속 소통의 단서가 여러 채널에 나뉘어 남습니다.

03

다음 전시의 근거가 부족합니다

작품 배치와 안내를 개선하고 싶어도 현장 경험을 데이터로 되짚기 어렵습니다.

HOW IT WORKS

전시 준비부터
다음 기획까지 연결합니다.

갤러리는 전시 정보를 등록하고, 관람객은 QR을 통해 기록을 남깁니다. RestArt는 그 기록을 작품과 전시 공간에 연결해 갤러리가 확인할 수 있는 형태로 정리합니다.

전시 정보 등록

전시 기본 정보와 포스터, 작품 목록, 배치도를 등록합니다.

EXHIBITION SETUP

작품·구역 데이터 검수

작품과 구역의 연결을 확인하고, 필요한 정보는 운영자가 보완합니다.

HUMAN REVIEW

관람객의 기록 축적

관람객은 QR로 진입해 작품을 촬영하고 리플릿과 관심 기록을 남깁니다.

VISITOR EXPERIENCE

리포트와 다음 인사이트

작품·고객·구역 반응을 살펴보고 다음 전시 운영의 참고 자료로 활용합니다.

MEASURE WITH CONTEXT

데이터의 의미와
한계까지 투명하게.

좋은 리포트는 숫자를 크게 보여주는 것보다, 그 숫자가 무엇을 의미하는지 정확히 설명하는 데서 시작합니다. RestArt는 참여 기록과 추정치를 구분해 해석하도록 설계합니다.

참여 데이터 기준서비스에 참여한 세션 기준입니다. 전시장 전체 입장객 수와 동일하지 않습니다.
기록과 관심의 구분촬영 기록은 관심 등록이나 구매 의사로 자동 해석하지 않습니다.
추정치의 명시체류 시간과 구역 전환은 촬영 기록에서 추정하며 실제 이동 경로가 아닙니다.
사람의 검수작품과 구역 데이터는 자동 생성 결과를 사람이 검토·보완하는 방식을 지향합니다.

QUESTIONS

도입 전에
궁금한 점.

RestArt는 갤러리 CRM인가요?

현재 소개하는 핵심은 전시 참여 데이터와 작품·구역 반응을 연결하는 갤러리 인텔리전스입니다. 일반적인 영업 CRM, 재고·회계·판매 관리 전체를 제공한다고 설명하지 않습니다.

전시장에 방문한 모든 관람객이 분석되나요?

아닙니다. 리포트는 RestArt 관람 경험에 참여해 기록을 남긴 세션을 기반으로 합니다. 전시장 전체 입장객을 대표하는 통계로 해석해서는 안 됩니다.

작품에 얼마나 오래 머물렀는지 정확히 알 수 있나요?

촬영 시각과 작품·구역 연결을 바탕으로 체류를 추정하는 방향입니다. 실제 감상 시간이나 실내 위치를 직접 측정하는 기능으로 표현하지 않으며, 근거가 부족한 경우 추정 불가로 처리해야 합니다.

어떤 자료를 준비해야 하나요?

기본적으로 전시 정보, 포스터, 작품 목록, 배치도 자료를 기준으로 설계되어 있습니다. 실제 도입 시 파일 형식과 필수 항목은 전시 환경을 확인한 뒤 안내합니다.

지금 바로 실제 서비스를 도입할 수 있나요?

이 페이지는 서비스 방향과 기능을 설명하는 영업용 시안입니다. 실제 데이터 연동, 운영 정책, 도입 가능 범위와 일정은 상담을 통해 별도로 확인해야 합니다.
