## 1. 관람 흐름

QR 스캔 → 전시 포스터 + 입장(V-01, 기존) → 동의(V-02, 기존) → 촬영 안내(V-03, 기존, 숨김 가능) → 허브(V-15) `[가안]` → 기록하기(V-04) 또는 배치도(V-06) 반복 → 리플릿 생성하기 = 관람 종료 → 생성 대기(V-08) → 리플릿(V-09) → (선택) 내 사진·한줄평(V-10) → 저장(로그인 C-01) · 공유(V-11) `[결정]`

- 허브(V-15) `[가안]`: 경로 `/exhibitions/[exhibitionId]/hub`. `lib/screens.ts`에 없는 다음 번호로 둔다. V-07은 DESIGN_v2·CURSOR_BRIEF에서 시연 제외(라우트 없음, "부활시키지 않는다")라 쓰지 않는다. 동작 3개: 기록하기(V-04), 배치도(V-06), 하단 강조 "리플릿 생성하기". 기록 수는 "기록 n점"으로 보인다. 배치는 `docs/leaflet/wireframes/rowD_hub_map_draft.png`.
- 입장(V-01)·동의(V-02)·촬영 안내(V-03)는 기존 페이지를 유지하고 DESIGN_v2 토큰만 맞춘다. 동의(또는 안내 숨김) 다음 목적지는 허브다. 와이어프레임에 없는 화면을 만들지 않는다.
- 전제: 촬영 가능한 전시. 관람객은 사진을 찍는다.

### 1-1. 기록하기 화면 (V-04, 카메라)
- 하단 3칸: 좌 = 나의 기록(마지막 기록 썸네일 + 기록 수 배지, 누르면 V-05 기록 목록) `[결정]` / 가운데 = 촬영 버튼 / 우 = 배치도 아이콘(V-06) `[가안]`
- 상단: 좌 "기록 n점", 우 "리플릿 생성하기" 버튼 `[가안]`

### 1-2. 촬영 후 하단 시트 (V-04 위) `[가안]`
- 촬영하면 카메라 위로 시트가 올라온다: 작품 썸네일, 작품명, 작가 · 연도, "다른 작품이에요"
- 시트 가운데: 15감성 원형 선택 "어떤 느낌이었나요?"
- 시트를 위로 끌면 작품 설명이 펼쳐진다.
- 감성을 누르면 기록 저장 → 시트가 내려가고 썸네일이 좌측 나의 기록으로 들어가는 움직임 → 바로 다음 촬영.
- 설명을 펼친 상태에서는 감성을 눌러도 시트를 닫지 않고, 하단에 "계속 촬영하기" 버튼을 보인다.
- 뒤로 가기로 카메라에 돌아가는 방식은 쓰지 않는다.
- 감성 없이 시트를 내리면 사진만 기록한다. V-05에서 나중에 감성을 고를 수 있다.
- "다른 작품이에요": 작품 목록(배치도와 같은 목록)에서 직접 고른다.

### 1-3. 배치도 경로 (V-06 → 시트)
- 배치도 → 작품 선택 → 같은 시트(설명 펼친 상태 + 감성 선택).
- 이 기록은 `source: "map"`(설명만 본 기록)으로 저장한다. 촬영 기록과 따로 집계한다.
- 배치는 `docs/leaflet/wireframes/rowD_hub_map_draft.png`의 배치도·작품 설명 시트. 15감성 선택기는 촬영 후 시트와 같다.

### 1-4. 리플릿 생성 조건과 기록 0점 알림 `[결정 + 가안]`
- 리플릿을 만들려면 기록이 1건 이상이어야 한다. 조건: 작품 촬영(`source: "camera"`) 1점 이상, 또는 배치도 작품 설명에서 감성 1개 이상 선택(`source: "map"`이고 `emotionId`가 있음).
- 조건 미충족일 때 "리플릿 생성하기"를 누르면 리플릿을 만들지 않고 알림만 띄운다. 버튼을 비활성으로 두지 않는다. 생성 대기(V-08)로 가지 않는다.
- 알림 문구 `[가안]`: "작품을 1점 이상 촬영하거나, 배치도에서 작품 설명을 보고 감성을 하나 선택해 주세요." 확인 버튼: "확인". 화면에 이 문구 외의 설명을 붙이지 않는다.
- 생성된 리플릿에는 항상 기록이 1건 이상 있고, 카드 2·3을 항상 보인다. 기록 0건 리플릿과 전시 대표 이미지 대체 경로는 없다.

## 3. 예술적 취향 유형 `[결정]`

유형명 = 감상 무드 × 관람 스타일.

### 3-1. 감상 무드
- 고른 감성을 6계열로 묶어 가장 많은 계열이 무드다. 작품 라벨은 동점 처리에만 쓴다.

| 무드 ID | 이름 | 15감성 (ID) |
|---|---|---|
| `bright` | 밝은 | 행복 `happiness`, 기쁨 `joy`, 사랑 `love` |
| `sensory` | 감각적인 | 세련됨 `sophistication`, 감각적 `sensuous` |
| `wonder` | 경이로운 | 호기심 `curiosity`, 경외심 `awe` |
| `reflective` | 사색적인 | 슬픔 `sadness`, 걱정 `worry`, 혼란 `confusion`, 공포 `fear` |
| `intense` | 강렬한 | 미움 `hatred`, 노여움 `anger`, 욕심 `greed` |
| `tender` | 다정한 | 동정 `compassion` |

- 동점: 기록한 작품들의 15감성 라벨을 계열별로 더해 큰 쪽 `[가안]`. 그래도 같으면 위 표 순서 `[가안]`.
- Top1 감성(카드 3·4 문구용): 가장 많이 고른 감성. 동점이면 라벨 합, 그래도 같으면 위 표의 감성 순서 `[가안]`.

### 3-2. 관람 스타일 (기준 v1, 2026-11-20 PM 개정)
- 세 조건을 각각 독립적으로 확인한다. 여러 개 충족하면 대표 = 수집가 > 탐험가 > 몰입가.
- `judgeStyle()`은 대표 스타일만 돌려준다. 보조 관람 성향은 계산하거나 저장하지 않는다 `[결정]`.

① 유효 관람 시간 (작품별)
- `유효 = 다음 작품 촬영 시각 − 이 작품 촬영 시각 − movingSec`, 0 미만은 0.
- 같은 작품을 연속 촬영하면 한 기록으로 합친다(첫 촬영 시각 사용, movingSec 합산).
- 상한 600초(10분). 휴식 제외 기준이 아니라 이상 구간 방지용이다.
- 마지막 작품은 리플릿 생성하기 시각까지 계산한다(임시, 별도 검증).
- `map` 기록은 시간 축에 넣지 않는다 `[가안]`.

② 몰입가: 유효 관람 시간 60초 이상인 작품이 1점 이상. 유효 시간 데이터가 없으면 불충족.

③ 탐험가: 기록이 있는 고유 구역 수(구역 = 갤러리가 등록한 벽면, 프로토타입은 `Artwork.zone`). 이동 횟수는 쓰지 않는다.

| 전체 구역 수 | 필요한 기록 구역 수 |
|---|---|
| 1 | 판정 제외(불충족) |
| 2~3 | 2 이상 |
| 4~5 | 3 이상 |
| 6~7 | 4 이상 |
| 8 이상 | ceil(전체 × 0.5) 이상 |

④ 수집가: 촬영한 고유 작품 수 ≥ 필요 수. `map` 기록은 세지 않는다.

| 전체 작품 수 | 비율 | 최소 | 필요 수 |
|---|---|---|---|
| 1~4 | 판정 제외(불충족) | - | - |
| 5~10 | 70% | 없음 | ceil(n × 0.7) |
| 11~20 | 60% | 7 | max(7, ceil(n × 0.6)) |
| 21~40 | 50% | 12 | max(12, ceil(n × 0.5)) |
| 41~60 | 40% | 20 | max(20, ceil(n × 0.4)) |
| 61 이상 | 30% | 24 | max(24, ceil(n × 0.3)) |

- 비율과 60초는 초기 실험값이다. 실제 관람 데이터로 검증한다.

### 3-3. 오늘의 산책자 `[결정]`
- 세 조건 모두 불충족이거나, 기록이 있어도 유형을 판정할 수 없으면 "오늘의 산책자". 화면은 하나다.
- 내부 사유 코드 `walkerReason`은 선택이다. 쓰면 `no_condition`(세 조건 불충족) 정도만 두고, 화면에 보이지 않는다.
- 기록 0건은 이 유형으로 리플릿을 만들지 않는다(1-4).

### 3-4. 유형명과 한 줄 설명 (화면 문구) `[결정]`

| 무드 | 몰입가 | 탐험가 | 수집가 |
|---|---|---|---|
| 밝은 | 밝은 몰입가 | 설렘 탐험가 | 행복 수집가 |
| 감각적인 | 감각 몰입가 | 미감 탐험가 | 컬러 수집가 |
| 경이로운 | 경이 몰입가 | 호기심 탐험가 | 영감 수집가 |

| 다정한 | 공감 몰입가 | 이야기 탐험가 | 마음 수집가 |

| 컬러 수집가 | 눈에 들어온 색들을 빠짐없이 모아 왔어요. |
| 경이 몰입가 | 압도되는 작품 앞에서 한참을 멈춰 섰어요. |
| 호기심 탐험가 | 궁금한 것을 따라 전시 구석구석을 누볐어요. |
| 영감 수집가 | 새로운 생각을 건네준 작품들을 차곡차곡 담았어요. |
| 여운 몰입가 | 작품이 남긴 여운이 길게 이어졌어요. |
| 사유 탐험가 | 작품 사이를 오가며 천천히 생각을 이어 갔어요. |
| 감정 수집가 | 작품마다 다른 마음을 솔직하게 남겼어요. |
| 강렬 몰입가 | 강한 인상을 준 작품을 피하지 않고 마주했어요. |
| 경계 탐험가 | 낯선 작품에도 먼저 다가갔어요. |
| 인상 수집가 | 마음을 흔든 장면들을 놓치지 않고 남겼어요. |
| 공감 몰입가 | 작품 속 누군가의 마음에 오래 귀 기울였어요. |
| 이야기 탐험가 | 작품마다 숨은 이야기를 찾아 전시를 걸었어요. |
| 마음 수집가 | 작품이 건넨 다정한 마음들을 모아 왔어요. |
| 오늘의 산책자 | 가볍게 둘러본 오늘, 다음엔 한 작품 더 남겨 보세요. |

### 3-5. 버전 `[결정 제안]`
- 리플릿에 `ruleVersion`을 저장한다. 생성된 리플릿의 유형은 바꾸지 않는다. 기준이 바뀌면 버전을 올린다. 마이룸 누적 유형을 다시 계산할 때만 새 버전을 쓴다.

## 4. 나와 닮은 작품과 대표 이미지

  - 카드 5 "추천 작품"은 같은 `dbRecommendationIds` 1~2개.
- 이미지: 갤러리 등록 작품 이미지 우선, 없으면 관람객 촬영 사진 `[이미지 사용 권한 확인 필요]`.

1. 내 사진을 추가했으면 내 사진.
2. 아니면 나와 닮은 작품.
- 기록 0건 리플릿과 전시 대표 이미지 대체 경로는 없다(1-4).

### 4-1. 닮은 이유 문구 `[가안, 예시]`
- 겹침 판정: 감성 겹침 = 내 Top1 감성이 작품 15감성 벡터 상위 3위 안. 색 겹침 = 내 Top1 색(무채색 제외)이 작품 65색 비율 15% 이상.
- 기록한 작품일 때: 스타일 × 겹침 표.

| 스타일 | 감성 | 색 | 둘 다 |
|---|---|---|---|
| 몰입가 | 가장 오래 머문 작품 중 '{감성}'이 가장 진하게 담긴 작품이에요. | 오래 바라본 이 작품의 {n}%가 {색이름}이에요. | '{감성}'과 {색이름}, 오래 머문 이유가 이 작품에 모두 있어요. |
| 탐험가 | 전시를 돌며 가장 많이 고른 '{감성}'이 이 작품에서 가장 짙어요. | 곳곳에서 모은 {색이름}이 이 작품을 {n}% 채우고 있어요. | 이번 여정의 '{감성}'과 {색이름}이 이 작품 한 점에 모여 있어요. |
| 수집가 | 모은 작품 중 '{감성}'을 가장 닮은 작품이에요. | 모은 색 가운데 {색이름}이 이 작품에 {n}% 담겨 있어요. | '{감성}'과 {색이름}, 오늘의 수집을 한 점으로 보여 주는 작품이에요. |
| 오늘의 산책자 | 오늘 기록한 작품이에요. | 오늘 기록한 작품이에요. | 오늘 기록한 작품이에요. |

- 기록한 작품, 겹침 없음: 그 작품이 유효 관람 시간 1위면 "가장 오래 머문 작품이에요.", 아니면 "오늘의 기록과 가장 닮은 작품이에요." `[가안]`
- 기록하지 않은 작품 `[결정]`: 감성 겹침이면 "이번엔 지나친 작품이지만, 오늘 고른 '{감성}'을 가장 닮았어요.", 아니면 "오늘의 기록과 가장 닮은 작품이에요."
- `{n}`: 그 색의 작품 내 비율(반올림 정수).

## 5. 카드 구성
- 카드 5장: 1 표지 / 2 나의 기록 / 3 나의 감성 / 4 이 전시의 감성 / 5 다음 감상. 배치는 `LEAFLET_CARDS.md`가 기준이다. 기존 세로 티켓 레이아웃은 쓰지 않는다.
- 카드 4에 "모양으로 보기"는 없다. 만들지 않는다.
- 카드 2·3은 항상 보인다(1-4). 카드 5장을 숨기는 분기를 두지 않는다.
- 카드 1 "기록 n점 · n분" `[가안]`: n점 = 기록한 고유 작품 수(`camera` + `map`), n분 = 첫 기록부터 리플릿 생성까지(반올림, 최소 1분).
- 전시 정보(참여작가 2~3명 + 외 n명)는 카드 1 하단. 장르는 넣지 않는다.

### 5-1. 카드 4 문구
- 그 감성을 Top1으로 고른 이전 관람객이 0명: "이 전시의 첫 번째 '{감성}' 관람자예요" `[결정]`
- 그 외: "'{감성}'을 고른 {n}번째 관람자예요" (n = 이전 관람객 수 + 1) `[가안]`
- 관람객 1명이어도 카드를 보인다 `[결정]`. 이전 관람객 분포는 프로토타입에서 `otherVisitorsTop1` 모의값.

## 6. 누적 집계 (카드 5 나의 누적) `[결정]`
- 기준: 전시 수. 한 전시 = Top1 감성 1회, Top1 색 1회.
- 같은 전시를 두 번 기록하면 리플릿은 둘 다 보관하고, 누적에는 그 전시 1회로 최신 기록의 Top1을 쓴다 `[가안]`.
- 표시: Top 감성 2개(n회) · Top 색 2개(n회). 동점이면 최근 전시의 값을 앞에 `[가안]`.
- 비회원은 지금 리플릿 1장만으로 계산한다. "상위 10% 감상자"는 만들지 않는다.
