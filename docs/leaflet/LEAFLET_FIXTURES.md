# 리플릿 모의 전시와 시나리오 (프로토타입)

- 데이터 원본: `docs/leaflet/leaflet-fixtures.json`. 앱은 `data/leaflet-fixtures.json` 사본을 쓰고, 테스트로 두 파일이 같은지 확인한다.
- 모든 값은 모의 값이다 `[가안]`. 작품 라벨(15감성·65색)과 RestArt DB 작품(`mockDb`)은 실제 R&D 데이터가 아니다. '세 개의 문' 샘플 이미지는 내부 R&D 전용이라 쓰지 않는다.
- 시연 방식: 카메라 촬영과 감성 누르기는 실제로 한다. 작품 인식, 촬영 시각, 이동 감지 시간, 구역은 시나리오 값을 n번째 촬영에 차례로 붙인다 `[기술 확인 항목의 모의]`.

## 1. 모의 전시 `ex-edge` (빛의 가장자리) — 12점, 4구역(벽면)

| 구역 | 작품 (기존 5점 유지, 신규 7점) |
|---|---|
| 입구 | aw-plane 맞닿은 면, aw-edge 가장자리 4, **aw-e06 첫 번째 문턱** |
| 창가 | aw-window 서쪽 창, **aw-e07 오후의 틈**, **aw-e08 먼 빛** |
| 중앙홀 | aw-navy 느린 남색, aw-fold 접힌 낮, **aw-e09 깊은 정오** |
| 복도(신규 구역) | **aw-e10 긴 복도**, **aw-e11 남은 온기**, **aw-e12 닫힌 색** |

- 기준값: 전체 작품 12 → 수집가 필요 촬영 수 = max(7, ceil(12 × 0.6)) = max(7, 8) = **8**. 전체 구역 4 → 탐험가 필요 구역 수 = **3**. 몰입가 = 유효 60초 이상 1점.
- 신규 작품의 이미지는 `scripts/gen-images.mjs`에 SVG를 추가해 만든다. 연도·설명·가격은 비워 둔다(지어내지 않는다).
