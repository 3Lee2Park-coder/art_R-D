# 리플릿 카드 레이아웃 v1

- 원본: PM 문서 `리플릿_카드_레이아웃_v1.md`. 와이어프레임: `docs/leaflet/wireframes/` (PM 승인). Figma: https://www.figma.com/design/WVKS46oSaaBHNVmYx1r7Sl
- 리플릿 카드 영역은 이 문서와 rowA·rowB 와이어프레임만 따른다. `DESIGN_v2.md` 부록 B의 세로 스크롤 티켓형과 `CONTRIBUTING.md`의 `public/leaflets/Leaflets-ticket.png`는 무시한다. 기존 티켓 레이아웃으로 그리거나 폴백하지 않는다.
- 간격: PM이 2026-11-20에 "카드 아래가 비니 요소 사이 간격을 조금씩 넓힌다"고 정했다. PNG는 넓히기 전 모습이다. 픽셀 값은 PNG에서 재지 말고, 카드 높이를 9:16로 고정한 뒤 요소 간격을 넓혀 아래 빈 곳을 줄인다. Figma 최신본과 다르면 Figma를 따른다.
- 카드 안의 글자는 아래 "화면 문구"만 쓴다. 설명 문장을 덧붙이지 않는다.

## 공통
- 9:16, 모바일 390px 기준 좌우 여백 24px, 위에서 아래로 한 줄 흐름. 최대 폭 480px 중앙(DESIGN_v2 리플릿 규칙).
- 배경: 리플릿에 저장된 테마 색(LEAFLET_SPEC 7-3). 본문 글자 자동(#111111 / #FFFFFF / 예외 #000000), 보조 글자 70%.
- 감성 칩·작품 이미지가 배경과 대비가 낮으면 1px 테두리(본문 글자색 20%).
- 하단: 5개 점 페이지 표시, 좌우로 넘기기(터치 스와이프 + 키보드 좌우 화살표).
- 카드마다 가장 큰 요소는 1개.

## 카드 1 표지
1. 상단 한 줄: RestArt 로고(좌) · 기록 날짜(우, `2026.11.19` 형식)
2. 대표 이미지(폭 100%, 세로 약 50%, 세로형 액자). 규칙: LEAFLET_SPEC 4
3. 유형명(가장 큰 글자)
4. 한 줄 설명(본문 크기)
5. 구분선
6. 전시 타이틀 / 갤러리명 · 지역 / 기록 n점 · n분
7. 참여작가 2~3명 + 외 n명(작은 글자)

## 카드 2 나의 기록
1. 제목 "나의 기록" + 우측 "기록 n점"
2. 작품 캐러셀(가장 큰 요소): 사진, 작품명, 작가 · 연도, 고른 감성 칩(감성 색). 감성 없는 기록은 칩 없음.
3. 캐러셀 아래 작은 썸네일 줄(기록 순서, 각 썸네일에 감성 색 점)
4. 한줄평 인용 블록(있을 때만)
5. "작품 문의" 보조 버튼

## 카드 3 나의 감성
1. 제목 "나의 감성"
2. 15감성 원형 지도(가장 큰 요소): 6계열로 묶은 15개 꽃잎, 고른 감성만 감성 색으로 채우고 고른 횟수만큼 길게. 안 고른 꽃잎은 윤곽선만(어두운 감성 색이 배경에 묻히지 않게, 와이어프레임 결정).
3. 소제목 "나의 색": 상위 5색 비율 폭 띠 + 색 이름 + 비율(%)
4. 소제목 "나와 닮은 작품": 썸네일(좌) + 작품명 · 작가 · 닮은 이유 한 문장(우)

## 카드 4 이 전시의 감성
1. 제목 "이 전시의 감성" + "관람객 n명의 기록"
2. 감성 단어 블록(가장 큰 요소): 전체 관람객이 고른 감성 단어 블록, 내 감성 블록만 감성 색으로 채움(기록 0건이면 채움 없음)
3. 문구 한 줄: LEAFLET_SPEC 5-1 (기록 0건이면 없음)
4. "전시 기록 더 보기" 버튼
- "모양으로 보기" 토글은 만들지 않는다.
- 카드 2·3은 항상 보인다. 기록 0건이면 리플릿 자체가 없다(LEAFLET_SPEC 1-4).

## 카드 5 다음 감상
1. 제목 "다음 감상"
2. 다음 전시 추천 1개(큰 썸네일 행)
3. 소제목 "추천 작품": 1~2개(작은 썸네일 행)
4. "나의 누적 · 전시 n곳": Top 감성 2개(n회) · Top 색 2개(n회)
5. "마이룸에 저장"(주 버튼, 폭 100%) / "공유하기"(보조 버튼)

## 기록하기 화면 (V-04, 와이어프레임 rowC, 가안)
- 상단: "기록 n점"(좌), "리플릿 생성하기"(우)
- 하단 3칸: 나의 기록 썸네일 + 수 배지 / 촬영 버튼 / 배치도 아이콘 + "배치도"
- 시트: 핸들, 작품 썸네일 · 작품명 · 작가 · 연도, "다른 작품이에요", "어떤 느낌이었나요?", 15감성 원형 버튼(원 안 "하나만 눌러 주세요"), "위로 올려 작품 설명 보기"
- "리플릿 생성하기"는 기록 0점이어도 눌린다. 조건 미충족이면 LEAFLET_SPEC 1-4 알림을 띄운다.

## 허브 · 배치도 (V-15 · V-06, 와이어프레임 rowD, 가안)
- 허브: 전시 제목, "기록 n점", "기록하기", "배치도", 하단 강조 "리플릿 생성하기".
- 배치도: 구역 칩, 작품 목록(썸네일 · 작품명 · 구역). 작품을 누르면 작품 설명 시트(설명 펼침 + 촬영 후와 같은 15감성 선택기). 기존 "담기", "자세히 보기"는 시트 하단에 유지.
- 기록 0점 알림: 허브(또는 기록하기) 위에 띄운다. 문구는 LEAFLET_SPEC 1-4.
